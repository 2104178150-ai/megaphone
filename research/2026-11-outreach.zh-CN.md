# 给 47 个新项目各提两三条具体建议之后，发生了什么

[English](2026-11-outreach.md) | 简体中文

2026 年 11 月。2026 年 10 月 18 日到 11 月 11 日，我们在 47 个新开源项目下各开了一个 GitHub issue。
每个 issue 根据 Megaphone 的体检结果，点出两三条具体、改起来不费事的地方（许可证、首屏截图、一行安装、
发个版本……），说明为什么，不要求任何回报。这一页统计截至 2026 年 11 月 14 日的结果。

**一句话总结**

- **至少每三位作者里就有一位改了仓库。** 现在还能打开的 46 个 issue 里，14 个得到了作者回复；
  至少 14 个项目在我们的 issue 之后改了仓库：回复的 14 位里有 13 位改了（第 14 位说以后再改，尚未复查），另有 1 位没回复、直接改了。
- **要么一天内回，要么要等很久。** 第一次回复的中位数是 23 小时，最快 10 小时，最慢 143 小时（六天）。
- **这次用中文写的 issue 效果更好：** 32 个里 12 个得到回复、12 个改了仓库，英文 14 个里各只有 2 个。
  我们一般按项目 README 的语言来写，所以这里比较的既是语言，也是不同的作者群体。
- **侧栏里的小改动每次都被采纳。** 在我们复查过的项目里，建议加的 topics（5/5）、About 简介（4/4）、
  网站链接（3/3）全都加上了。首屏截图或演示是我们提得最多的一条，被采纳的比例反而低一些（10 次里 6 次）。

## 哪类建议会被采纳

把 issue 里每一条编号建议按类型归类。"提了几次"统计全部 46 个能打开的 issue；"采纳"只有我们复查过的
16 个项目才知道（14 个改了仓库的，加上 2 个关掉 issue 但什么都没改的），所以应理解为"采纳者有多常接受这类建议"，
而不是整体采纳率。

| 建议类型 | 提了几次 | 采纳（复查过的） |
|---|---|---|
| 首屏放截图、GIF、视频或真实输出 | 31 | 10 次里 6 次 |
| 一行安装或一步试用 | 23 | 5 次里 3 次 |
| Topics | 17 | 5 次里 5 次 |
| 打一个版本（release） | 15 | 6 次里 5 次 |
| 许可证 | 14 | 6 次里 4 次 |
| README 结构或第二语言 | 14 | 5 次里 4 次 |
| About 简介 | 13 | 4 次里 4 次 |
| About 里的网站链接 | 7 | 3 次里 3 次 |
| Agent Skill 的 description | 3 | 1 次里 0 次 |
| 其他 | 2 | 未复查 |

最省事的、在 About 侧栏里就能改的几条，每次都有人做。截图、演示或一行安装要真花功夫，
采纳者最常把它们留到以后。

## 我们的体会

- **如果只有十分钟，先把 About 侧栏填好：** 一句话简介、网站链接、几个 topics。被建议这么做的采纳者都做了。
- **把具体的文件、行、截图点出来。** 有一位作者从没回复，却完全按我们写的改了（给我们点名的示例目录截图，
  放在我们说的位置）：建议够具体，就不需要来回沟通。
- **准备好被纠正。** 有位作者指出我们标为有问题的一条安装命令其实是对的；我们当天就[改了检查程序](../skills/launch-audit/scripts/audit.py)。

## 方法

- **写给谁。** 新建不久的公开仓库，很多是 Agent Skills 或 Claude Code 插件，从 GitHub 搜索和中文开发者列表里手工挑选。
  每个都先用 [`audit.py`](../skills/launch-audit/scripts/audit.py) 体检过；只有能提出具体、改起来便宜的建议时才写。
  每个仓库最多一个 issue。
- **怎么算。** "回复"指作者在 issue 下留言，或用 pull request 回应。"改了仓库"指我们手工复查时，仓库里已经有至少一条
  我们建议的改动，且发生在 issue 之后。那位没回复的作者，改动来自我们的 issue 是我们根据吻合程度做的推断。未复查的仓库按未改计，所以这是下限。
- **怎么归类。** 每条编号建议手工归为一个类型；一条建议同时涉及两件事（比如简介和 topics）时，两类各记一次。
- **局限。** 样本小，来自同一个发送者，只有四周；11 月 11 日开的 issue 才三天，之后可能还有回复。仓库是我们挑的，
  不是新项目的随机样本。语言和作者群体混在一起（见上）。各类建议的采纳情况只对复查过的项目已知。
