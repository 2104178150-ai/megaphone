# 阮一峰《科技爱好者周刊》

> **English summary:** One of the most-read Chinese tech newsletters, published every
> Friday. Submit articles, software or resources — including your own project — by
> opening an issue on github.com/ruanyf/weekly. Recent self-submissions use titles like
> 「【开源自荐】名字：一句话」.
>
> 最近核对：2026-10，依据 [ruanyf/weekly 的 README](https://github.com/ruanyf/weekly) 和近期 issue。

## 适合什么项目

国内阅读量最大的科技周刊之一，**每周五发布**，内容覆盖面很广：文章、工具、资源，以及对广大技术读者
有用或有趣的开源项目。

## 怎么投稿

README 写明欢迎投稿**文章、软件、资源**，方式是在
[github.com/ruanyf/weekly/issues](https://github.com/ruanyf/weekly/issues) **提交 issue**。
可以推荐自己的项目，是否收录由作者决定。

近期自荐 issue 的标题大多是 **「【开源自荐】名字：一句话介绍」** 这种格式，照着写，方便作者一眼识别。

## 怎样更容易被收录

- **非专业读者也能看懂的一句话价值**：读者面很广。
- 链接对国内读者友好（仓库 + 在线体验），尽量避免需要特殊网络才能打开的页面。
- issue 里用中文介绍，即使项目本身是英文的。
- 先翻几期周刊，看工具是怎么被介绍的：简短、客观，一两句话加一个链接。照这个风格写，作者更容易直接采用。
- 建议在周一到周三提交，赶上当周周五的那一期。

## 模板

```
标题：【开源自荐】<名字>：<一句话介绍>

<名字>（<仓库链接>）是一个 <类别>，可以 <做什么>，适合 <谁>。

亮点：<最特别的一点>。
在线体验 / 安装：<链接或一行命令>
协议：<开源协议>

谢谢阮老师！
```

## 常见坑

- issue 写成长篇推广文 → 按周刊会印出来的样子写。
- 同一个项目开好几个 issue。
