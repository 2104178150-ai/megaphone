# 阮一峰《科技爱好者周刊》

> Last checked: 2026-10 against the [ruanyf/weekly README](https://github.com/ruanyf/weekly).

## Fit

One of the most widely read Chinese tech newsletters. It **publishes every Friday** and
covers technology broadly: articles, tools, resources, and open-source projects that
are useful or interesting to a wide technical audience.

## How to submit

The README says submissions of **articles, software and resources** are welcome, by
**opening an issue** at [github.com/ruanyf/weekly/issues](https://github.com/ruanyf/weekly/issues).
You can recommend your own project. Inclusion is the editor's choice.

## What helps

- **One-sentence value** a non-specialist understands — the audience is broad.
- A link that works for Chinese readers (repo + demo; avoid pages that need a VPN to
  load if you can).
- Chinese description in the issue, even if the project is in English.
- Look at a few recent issues of the weekly to see how tools are described: short,
  factual, one or two sentences plus a link.

## Template (issue)

```
标题：【自荐】<名字>：<一句话介绍>

<名字>（<仓库链接>）是一个 <类别>，可以 <做什么>，适合 <谁>。

亮点：<最特别的一点>。
在线体验 / 安装：<链接或一行命令>
协议：<开源协议>

谢谢阮老师！
```

## Pitfalls

- Long promotional issue text → write it the way the weekly would print it.
- Opening several issues for the same project.
